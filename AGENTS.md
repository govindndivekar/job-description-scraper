# JobDescriptionScrapper

Personal career-page collector for Govind Divekar.

- Target roles: QA, software testing, test automation, SDET
- Location: Bengaluru / Bangalore only (office or hybrid)
- Public listings only. Do not guess passwords or bypass login/CAPTCHA.
- Crawl in small shuffled batches with jittered delays. Never hammer a host.
- Prefer official ATS JSON APIs over HTML scraping.
- Live SQLite lives in `data/` and is gitignored.
